# Synthetic UK Route Data

FleetGuard's route fixtures follow public UK railway geography along the Great
Western and South Wales corridors. They include London, Reading, Didcot,
Swindon, Chippenham, Bath, Bristol, Avonmouth, the Severn Tunnel area, Newport,
Cardiff, Bridgend, Port Talbot and Swansea.

The point set is deliberately compact: telemetry is interpolated between
corridor waypoints and therefore does not reproduce every bend, junction,
signal, siding or speed restriction. It must not be used for navigation or
operational railway decisions.

Terminal names, freight customers, consists, dwell durations and journeys are
fictional. They do not describe Tarmac, Network Rail, a train operator or any
other real organisation.

Geographic context is based on public map geography. When route geometry is
later refreshed from OpenStreetMap, retain the attribution “© OpenStreetMap
contributors” and record the extraction date and query beside the fixture.
